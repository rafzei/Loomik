# Loomik 1.1.0

## Changes

- Record **Camera only** as a full rectangular frame, with an optional microphone,
  without desktop capture or Screen Recording permission.
- Move and resize the camera-only preview. The image keeps its proportions and
  resizing the window does not change the saved video dimensions.
- Use mirroring, countdown, pause/resume, and PNG photos in camera-only mode.
  A disconnected or frozen camera produces an error and retains recovery files.
- Update the Linux capture dependencies to ashpd 0.12.3 and x11rb 0.14.0.
- Update source-built FFmpeg/FFprobe for macOS and Windows packages to 8.0.3,
  including the upstream security fixes described in [media-tools.md](../media-tools.md).

## Verification and platform limits

Camera-only regression tests cover frame timing, full-frame resizing/mirroring,
decoded movie edges, pauses, countdown cancellation, and disconnect recovery.
The preview has also been checked with synthetic camera frames on macOS.
These checks do not establish physical camera/microphone or Wayland behavior.

Publication requires native build and package verification for the exact release
commit on Apple Silicon, Intel, Windows MSVC, and Ubuntu. See
[VERIFICATION.md](../../VERIFICATION.md) for the scope of recorded checks.
Linux desktop capture remains window-only with no cursor capture. Physical
Windows/Ubuntu device validation remains outstanding. macOS packages are ad-hoc
signed and not notarized; Windows packages are unsigned.
