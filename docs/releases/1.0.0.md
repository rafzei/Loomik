Loomik records your screen, an application window, or a local image/video background, with an optional movable camera circle and microphone narration. Recordings stay on your device; there is no account, upload, or application-imposed time limit.

### Downloads

- **macOS 13+, Apple Silicon:** `Loomik-1.0.0-macOS-arm64.dmg` or `.zip`.
- **macOS 13+, Intel:** `Loomik-1.0.0-macOS-x86_64.dmg` or `.zip`.
- **Windows 10 2004+ / Windows 11, x64:** `Loomik-1.0.0-Windows-x64.zip`. Extract the entire folder, then open `Loomik.exe`.
- **Ubuntu 24.04 LTS, amd64:** `Loomik-1.0.0-Ubuntu-24.04-amd64.deb`. Install using `sudo apt install ./Loomik-1.0.0-Ubuntu-24.04-amd64.deb`.

macOS and Windows include FFmpeg/FFprobe. Ubuntu installs dependencies through APT. No Rust toolchain is needed to use these downloads. Corresponding media-tool sources, build recipes and third-party license notices accompany the applications. Verify downloads with `SHA256SUMS.txt`.

### Included

- MP4, MOV and MKV export with H.264 and microphone AAC audio; PNG snapshots.
- Floating controls, pause/resume, elapsed-time display and 3–2–1–0 countdown.
- Draggable windows, custom selectors, and whole-app X with save-before-quit handling.
- Camera selection, circular overlay, movement, resizing and mirroring.
- PNG/JPEG and MP4/MOV/MKV/WebM backgrounds, Fit/Fill, seeking, hold/loop and source-audio/microphone mixing.
- Bounded capture/decoder buffers, acquisition timestamps, pause-aware audio synchronization and hardware encoding where supported.

### Verification and limitations

Native macOS screen/camera/microphone recording and synchronization have been tested. Automated native builds, encoding/decoding checks and package checks cover the platforms above; Ubuntu additionally exercises X11 window isolation and GUI startup under Xvfb. **Windows and Ubuntu physical camera/microphone, DPI and Wayland compositor verification will be performed after this release.** Automated checks are not a physical lip-sync or hardware performance measurement.

Linux records isolated windows via portal/PipeWire on Wayland or XComposite on X11. Whole-monitor and cursor capture are unavailable there. Position the camera inside Recording studio; global floating-window/countdown placement depends on the compositor. Choose another application's window in the Wayland picker.

macOS packages are ad-hoc signed and **not notarized**. Windows packages are **unsigned**. Your OS may ask you to allow opening the downloaded application; follow the included installation instructions. Grant screen/camera/microphone permissions when using those features.

Bundled Windows encoding supports NVIDIA NVENC with a compatible driver and software x264 fallback. Intel QSV/AMD AMF need an external FFmpeg build with those encoders. System/desktop audio capture is not included. Source-video audio is decoded during export; keep the source file available until saving finishes. Actual latency depends on the devices and their frame cadence; zero physical latency is not guaranteed.

See the README, platform guides and VERIFICATION.md for setup, measurements and remaining checks.
